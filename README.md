# TCJ Accent WordPress Website

Custom WordPress website developed for TCJ Accent, an interior and upholstery company.

## Project Overview
This project includes a custom WordPress theme and tailored customizations
on top of selected WordPress plugins and page builders to meet client needs.

## What’s Included
- Custom WordPress theme development
- Theme customization (layout, styles, templates)
- Plugin configuration and custom tweaks

## Technologies Used
- WordPress
- PHP
- HTML
- CSS
- JavaScript

## Notes
WordPress core files, database, and media uploads are intentionally excluded
for security and size reasons.
